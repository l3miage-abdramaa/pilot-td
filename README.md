# PILOT-TD

Application de suivi des projets d'une institution au Tchad :
enregistrement des projets, suivi de l'avancement par étapes,
et tableau de bord pour la direction.

## Stack
- Backend : Java 25, Spring Boot 4.1
- Base : PostgreSQL, Flyway
- Frontend : Angular
- Conteneurs : Docker

## Structure
- `backend/` : application Spring Boot
- `frontend/` : application Angular
- `infra/` : Docker Compose, déploiement
- `docs/` : besoins, modèle métier, décisions

## Documentation
- `docs/TASK-001-besoins.md` : besoins et user stories
- `docs/TASK-002-modele-metier.md` : modèle métier gelé et règles RG-*
- `docs/decisions.md` : journal des décisions
- `docs/carnet.md` : carnet d'apprentissage
