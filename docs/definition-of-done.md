# Définition de fini

Un ticket passe dans Terminé seulement si :

- [ ] Les critères d'acceptation sont tous vérifiés.
- [ ] Le code respecte les règles RG-* de TASK-002.
- [ ] Les tests sont écrits et passent.
- [ ] La CI est verte.
- [ ] Le code est fusionné dans main via une Pull Request.
- [ ] Je sais expliquer ce que j'ai fait avec mes mots.
- [ ] Le journal des décisions est à jour si une décision a été prise.
